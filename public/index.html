The journey: open the phone, toggle consent, hit SYNC. The /sync call runs a rule-based translator client-side, writes a FHIR Bundle to local hospital storage, and emits SSE telemetry the admin + operator pages pick up. Records persist in localStorage so a refresh doesn't wipe the demo. Click Clinician view in the drawer to see the data land in the mock EHR.
This static deploy runs entirely in the browser — no backend, no live Claude call. Full pipeline (whoop → gateway → hospital with real Claude Opus 4.7 translation) lives in the GitHub repo behind npm run dev.
