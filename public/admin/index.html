B

Gateway API

Consent filter + translator. Pulls a Whoop snapshot, drops any field the patient hasn't consented to, calls Claude Opus 4.7 to emit a FHIR transaction Bundle (with a rule-based fallback), and posts it to the hospital. Telemetry events stream over SSE.

C

Hospital API

FHIR receiver. Validates incoming transaction Bundles, stores Observations in memory, and runs threshold rules (high resting HR, low HRV, low SpO₂, poor sleep efficiency) to surface clinical alerts.
