Pipeline detail Whoop :4001 → Gateway :4002 → Hospital :4003

Each sync pulls a Whoop snapshot, filters metrics through consent, translates to a FHIR transaction Bundle (Claude Opus 4.7 with a rule-based fallback), and posts to the hospital endpoint. Stages animate as telemetry events arrive over SSE.
